# Внутренний сайт приёмной комиссии

Интерфейс реализован по предоставленному образцу: фиксированное боковое меню,
светлая рабочая область, четыре показателя, быстрые действия и таблица активности.
Шрифт Inter с кириллицей и SVG-иконки поставляются с проектом, внешние CDN не нужны.
Исходники, собранный сайт и скриншоты также находятся в `artifacts/bgtu-admissions-site.zip`.
Лицензии поставляемых шрифтов и библиотек сохранены в `frontend/public/licenses/`.

## Быстрый просмотр

```bash
cd frontend
npm ci
npm run dev
```

Команда выводит адрес Vite. Без Python-сервера можно посмотреть демо-режим:
все имена и показатели в нём вымышленные. Поиск, фильтры, карточки, добавление
абитуриента, план мест, статусы договоров, звонки и CSV работают в памяти вкладки.
Изменения демо сбрасываются при перезагрузке. Файлы Excel не импортируются в демо,
для этого нужно войти в рабочую базу. Демо не читает приложенную персональную выгрузку.

Vite проксирует `/api/*` на Python API на порту 8000. Для входа запустите Python API
в другом терминале согласно README. В рабочем режиме интерфейс показывает ответы
базы и ошибки сервера, не подменяя их демонстрационными значениями.

## Сборка и работа с базой

```bash
cd frontend
npm ci
npm run build
cd ..
# DATABASE_URL и JWT_SECRET задаются согласно README.
.venv/bin/python -m admissions create-user secretary
.venv/bin/uvicorn admissions.api:create_app --factory --host 127.0.0.1 --port 8000 --no-proxy-headers
```

После сборки FastAPI отдаёт сайт на `/`, статические файлы — на `/assets/`.
Маршрутизация через `#/registry`, `#/rankings` и другие hash-пути позволяет обновлять
страницу без настройки SPA fallback и без перехвата путей API.
Сборку нужно выполнить до запуска Python, чтобы зарегистрировались статические маршруты.
Для зависимостей используется `package-lock.json`; сборка проверяет TypeScript.

Нажмите «Подключить рабочую базу», введите логин и пароль созданного сотрудника.
JWT хранится только в памяти вкладки. После перезагрузки нужно войти снова.
Чужие или просроченные токены не открывают внутренние методы. Удалённые адреса
ограничены `INTERNAL_NETWORKS` на API; требования к reverse proxy описаны в README.

## Что работает

| Раздел | Действия |
|---|---|
| Дашборд | Реальные показатели кампании, дата, переходы в разделы, Excel-импорт, активность |
| Реестр | Поиск по ФИО/номеру, фильтры направления, квоты и статуса, страницы по 20 записей |
| Карточка | Личные данные, контакты, документы, заявления; редактирование имени и контактов |
| Новый абитуриент | Карточка и первое заявление сохраняются одной транзакцией, без частичного сохранения |
| Рейтинги | Выбор конкурсной группы, пять категорий, равные места при ничье, план мест, Excel/CSV |
| Договоры | Поиск, фильтры, создание для платного заявления, независимые место/этап, история, DOCX по загруженному шаблону |
| Оплата | Импорт подтверждений из Excel, отчёт с количеством изменений и ошибками строк |
| Звонки | Настройка сроков, очередь по приоритету, результаты и комментарии |
| Отчёты | Заполненность направлений, CSV статистики, Excel/PDF рейтинга, Excel бухгалтерии, JSON/XML для 1С |
| Журнал | Успешные операции с автором и временем, просмотр деталей, страницы по 15 событий |
| Профиль | Вход/выход, уведомления из журнала, помощь |

Показатели дашборда берутся из текущей базы. «Заявлений сегодня» определяется по
полю «Дата получения документов» импортированной строки, а не времени повторного импорта.
Если нет плана мест, переполнение не выдумывается: показано пояснение «План мест пока не задан».
Проценты роста из образца есть только в демо: для настоящих процентов нужна история срезов.

Дата демо — 14 августа 2026; настоящий режим использует московскую дату.
Для обзвона в рабочем режиме сначала укажите фактические сроки кампании. Эти даты
сохраняются в браузере отдельно по году и режиму; между сотрудниками не синхронизируются.
После задания дат обновляются счётчик звонков и карточка сроков в меню. Даты —
локальные параметры формирования очереди, не изменение официальных правил приёма.

В журнал добавляются новые успешные операции через API после установки этой версии.
Изменения напрямую через SQLite/старый CLI задним числом не восстанавливаются.
Времена событий передаются с явным UTC и выводятся по Москве.

## Браузерная проверка

```bash
.venv/bin/python -m pip install -r requirements-browser.txt
.venv/bin/python -m playwright install chromium
.venv/bin/python tests/browser_smoke.py
```

Если Chromium уже установлен системой, скрипт использует его; путь можно задать
через `CHROMIUM_PATH`. Проверка запускает отдельный Uvicorn на порту 18766,
создаёт временную SQLite-базу и случайный пароль, после завершения останавливает
сервер. Реальные данные и учётные записи не нужны.

Проверяются демо-навигация, поиск, редактирование карточки, категории рейтинга,
план приёма, результат звонка, CSV, мобильное меню, настоящий вход, добавление
заявления, импорт ЕПГУ, обновление договора, импорт оплаты, скачивание XLSX и выход.
Скриншоты сохраняются в `artifacts/` и содержат только демонстрационные данные.

Дополнительно:

```bash
.venv/bin/python -m pytest -q
cd frontend
npm run build
npm run format:check
```

## Ограничения версии

Это инструкция внутреннего сайта. Отдельный портал абитуриента описан в [PUBLIC.md](PUBLIC.md). Создание пользователей
выполняется CLI администратора. Редактор сложных документов, отмена приказа о зачислении
и настройка официальных правил конкурса в интерфейсе не реализованы.
Свойства родителя и расширенные персональные поля сохраняются API ядра; их отдельной формы
в этой версии интерфейса нет. Нагрузочные нормативы ТЗ отдельным тестом не подтверждены.
