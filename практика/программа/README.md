# АИС приёмной комиссии

Python 3.11+, FastAPI, SQLAlchemy, SQLite; интерфейсы React и TypeScript. Для сборки нужен Node.js 20.19+ либо 22.12+ (проверено также на Node.js 24).

## Установка и запуск

Выполните из каталога `практика/программа`:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
npm --prefix frontend ci --cache /workspace/.npm-cache
npm --prefix frontend run build
umask 077
export DATABASE_URL=sqlite:///data/admissions.sqlite3
export JWT_SECRET="$(.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(48))')"
.venv/bin/python -m admissions init-db
.venv/bin/python -m admissions create-user secretary
.venv/bin/uvicorn admissions.api:create_app --factory --host 127.0.0.1 --port 8000 --no-proxy-headers
```

Пароль пользователя вводится скрыто. Случайный JWT_SECRET действует до завершения оболочки; для постоянного развёртывания требуется защищённое хранение секрета. База создаётся локально и не включена в исходники.

Сервер обслуживает внутренний интерфейс `/`, портал `/abiturient/`, описание API `/docs` и проверку подключения к базе `/health`.

## Проверка

```bash
.venv/bin/python -m pytest -q
```

Тесты используют временные базы и синтетические данные. В копию не включены базы, учётные записи, виртуальное окружение, node_modules и сборка. Правила конкурсного отбора для СПО требуют отдельной адаптации и проверки до использования в реальном приёме.

## Демонстрация на Windows

Из этой папки запустите `start-practice.cmd`. Нужны Python 3.11+ и Node.js. Откройте [внутренний кабинет](http://127.0.0.1:8002/#/login) и войдите как `practice-secretary` с паролем `Practice-2026!BGTU`. Команда `python -m admissions practice-demo` заполняет отдельную базу `data/practice-demo.sqlite3` вымышленными записями. Для ручного запуска используйте эту базу и порт 8002 в приведённых выше командах запуска.

1. На странице **Главное** видны сводка, оплаченный договор и конкурсная группа с числом заявлений выше плана.
2. В **Рейтингах** выберите специальность 09.02.07 и основной конкурс. У Анны Волковой средний балл 4,91. План — два места. При равном балле кандидаты делят позицию.
3. В **Реестре** откройте карточку Волковой, вкладку **Заявления**. Там можно изменить средний балл и статус или зарегистрировать зачисление, указав реквизиты выданного приказа.
4. В **Договорах** откройте `ПК-2026-0004` и скачайте Word. Для проверки сверки оплат загрузите `demo/Оплаты_СПО.xlsx`. Для обзвона до импорта оплат задайте оба срока в пределах ближайших семи дней.
5. В **Главное → Загрузить Excel** можно загрузить `demo/Заявления_СПО.xlsx`, а в **Отчётах** проверить доступные форматы.

Учебный конкурс использует средний балл аттестата от 2,00 до 5,00 с точностью до сотых. Для СПО требуется столбец «Средний балл аттестата» или «Средний балл документа об образовании». Прикладные правила для льгот, равенства баллов и вступительных испытаний проверяются отдельно перед использованием в реальной кампании. Встроенный DOCX представляет учебный образец. Стоимость, график платежей и подписи указываются при оформлении.
