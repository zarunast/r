# Практика: АИС приёмной комиссии ПК БГТУ

- `текст/Отчёт_по_практике_АИС_ПК_БГТУ.docx` — отчёт о внутренней АИС приёмной комиссии, включающий анализ предметной области, моделирование и техническое задание. Редактируемый текст и рисунки находятся рядом.
- `текст/01_Анализ_области_использования.docx` — текст анализа для оформления работы.
- `текст/01_Анализ_области_использования.md` — редактируемая версия того же текста.
- `программа/` — отдельная копия исходников приложения, зависимостей и тестов для дальнейшей работы.

Текст описывает самостоятельную разработку системы с этапа анализа требований. Числовые показатели приведены как цели, которые предстоит проверить.

Учебная программа использует средний балл документа об образовании, план мест и тестовые данные колледжа. Для запуска на Windows выполните `программа/start-practice.cmd`. Правила конкурса для реальной кампании согласовываются отдельно.
