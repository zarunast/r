# Показ АИС приёмной комиссии

Распакуйте архив проекта и запустите `start-presentation.cmd`. После запуска Uvicorn откройте http://127.0.0.1:8001/. Оставьте окно сервера открытым. Запуск из архива GitHub использует установленные Python и Node.js, чтобы установить зависимости и собрать интерфейс. В архиве для Windows интерфейс уже собран.

| Роль | Логин | Пароль для показа |
| --- | --- | --- |
| Секретарь | `demo-secretary` | `Bgtu-Demo-2026!` |
| Преподаватель | `demo-teacher` | `Bgtu-Demo-2026!` |
| Редактор | `demo-editor` | `Bgtu-Demo-2026!` |

Сценарий работает с вымышленными данными в отдельной базе `data/presentation.sqlite3`. Для повторного запуска можно использовать тот же файл. Чтобы вернуться к исходному сценарию, остановите демосервер и переименуйте файл базы перед следующим запуском.

1. Войдите как секретарь. На странице **Главное** покажите два оплаченных договора и две переполненные программы. В каждой демонстрационной платной группе четыре заявления на одно место.
2. В **Договорах** откройте договор Новиковой Ирины Алексеевны `ДЕМО-2026-001`. Покажите регистрацию и подтверждённую оплату.
3. В **Рейтингах** выберите **09.03.04 Разработка программно-информационных систем**, очную форму и платную категорию. Нажмите **Сформировать приказ**, отметьте Новикову, введите номер `ДЕМО-01` и даты приказа и зачисления. Скачайте проект Word. Проект сохраняет текущие статусы заявлений.
4. Откройте **Звонки → Демо-сроки**. Появятся шесть платных заявления без подтверждённой оплаты. Покажите приоритет, сохранение результата звонка и **Скачать список CSV**. Оплаченные договоры в очередь не попадают.
5. В **Договорах → Создать договоры** найдите номера `99000000009` и `99000000010`, отметьте их платные заявления и нажмите **Создать и скачать**. В ZIP будут два Word-файла с последовательными номерами.
6. Войдите как преподаватель. В табеле найдите Новикову и Крылову. На их программах видны разные профильные экзамены. Сохраните изменение балла по одному предмету и покажите пересчёт итога.

## Правила расчёта и план мест

В отчёте БГТУ за 2019 год конкурсный балл рассчитывался по профильному предмету, математике и индивидуальным достижениям. Русский язык был неконкурсным. В проекте при ручном внесении баллов русский включён в сумму по заданию. Для ИТ учитывается информатика, для технических направлений механика или физика, для соответствующих экономических и педагогических направлений обществознание или предусмотренная альтернатива. Из каждой группы альтернатив берётся один результат в порядке настройки. Если обязательного результата нет, система показывает, какого предмета не хватает. Импорт сохраняет сумму из ЕПГУ.

План 2026 года по бакалавриату и специалитету доступен в **Рейтингах → Места бакалавриата и специалитета 2026**. Система подставляет цифры при однозначном совпадении кода, профиля и формы обучения. Для остальных групп сотрудник может задать места вручную.
