# Документация курсового проекта

Редакция от 31.10.2026, обновлена по дополнительному образцу оформления.

- [Отчёт Word](Курсовой_проект_АИС_ПК_БГТУ.docx) — редактируемый документ с рамками и основными надписями.
- [Отчёт PDF](Курсовой_проект_АИС_ПК_БГТУ.pdf) — версия для просмотра и печати.
- [Схемы и материалы](Схемы_и_материалы_АИС_ПК_БГТУ.zip) — исходники диаграмм, изображения, скриншоты, структура БД и API.
- [Проверка и внесённые правки](Проверка_и_внесённые_правки.md) — результаты проверки содержания и оформления.

В отчёте 171 страница, 78 таблиц и 48 иллюстраций: 19 актуальных схем, 12 прототипов и 17 скриншотов. Введение сокращено до одной страницы. Устаревшие 16 технических эскизов сохранены в ZIP и исключены из основной части.

Оформление согласовано с ГОСТ 7.32–2017, ГОСТ Р 2.105–2019 и правилами библиографических описаний и ссылок. Основные надписи — учебная адаптация форм 2 и 2а ГОСТ Р 2.104–2023 по предоставленному образцу. Обязательный локальный шаблон колледжа не предоставлялся. Подписи и даты согласования оставлены для фактического заполнения.

Проверены все 87 ссылок содержания, наличие рамок на каждом листе, отсутствие пустых страниц и выходов текста/изображений за поля. Дополнительные скриншоты сняты при успешном повторном браузерном сценарии на синтетической базе.

Реализованные функции и проектные доработки обозначены отдельно. Описание программы относится к исходному коду `853721f`; в этой редакции код приложения не изменён.
