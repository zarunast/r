## Приложения

- А — листинги программного кода: пять полных модулей Python-ядра.
- Б — SQL-скрипты создания восьми таблиц и пример обезличенного запроса.
- В — структура проекта, фактический прогон тестов и история Git.
- Г — план разработки по спринтам.

Расширенная концептуальная модель из 23 таблиц и служебные матрицы сохранены в архиве справочных материалов внутри ZIP. Они исключены из приложений основного отчёта.

Сохранены геометрия, сетка и шрифт рамок предоставленного образца. В штампах уточнены руководитель и группа; подписи и даты не выдуманы. Линии остаются векторными, номера листов — полями Word.
