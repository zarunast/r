# Проверка правок документа

Исправлена загруженная пользователем версия DOCX; исходный файл сохранён без изменений.

Выполнено:
- Названия глав приведены к форме предложения без точки в конце; технические аббревиатуры сохранены.
- Подзаголовки уровней 2 и 3 выровнены по центру.
- Маркированные списки Word переведены на тире; нумерованные списки сохранены.
- Сняты полужирное и курсивное начертания текста и заголовков таблиц, включая наследуемое оформление.
- Для всех абзацев 67 таблиц, включая таблицы с листингами, установлен одинарный межстрочный интервал.
- Сохранены одна Use-case (2.1), одна архитектурная (7.1), одна диаграмма классов (7.2), одна ER-диаграмма (8.1). Отдельная схема развёртывания заменена описанием с сохранением её содержания.

- Оглавление пересчитано по итоговому PDF; включено обновление полей при открытии в Word. Вёрстка проверена в LibreOffice. В Word возможны отличия пагинации из-за шрифтов и движка верстки.

## Последние правки по замечаниям пользователя

- Заголовки глав, подразделов, функциональных требований и подписи рисунков/таблиц выделены жирным. Основной текст остаётся обычным.
- Убрана заливка ячеек, в том числе заданная стилями таблиц; одинарный интервал сохранён. Заголовки столбцов обычных таблиц не выделены.
- Убран дополнительный боковой промежуток между текстовой областью и рамкой. Абзацный отступ — 1,25 см, боковые отступы абзацев — 0. Рамки и штампы сохранены.
- Добавлен рисунок 1.5 с четырьмя иллюстрациями аналогов. Изображения созданы генеративно и явно обозначены как схемы, не скриншоты программ.
- В текущем документе 198 страниц, 67 таблиц, 64 встроенных изображения. Все 20 записей оглавления сверены с итоговым PDF.
