# Тестовая выгрузка ЕПГУ

[bgtu-epgu-all-programs-10000.xlsx](bgtu-epgu-all-programs-10000.xlsx) содержит 10 000 вымышленных заявлений для проверки приёмной кампании 2026. Книга состоит из одного листа «Заявления» и сохраняет названия и порядок 60 столбцов исходного формата.

| Уровень подготовки | Программы и профили |
| --- | ---: |
| СПО | 5 |
| Бакалавриат | 51 |
| Специалитет | 7 |
| Магистратура | 32 |
| Аспирантура | 14 |
| **Всего** | **109** |

Программы СПО, бакалавриата, специалитета и магистратуры взяты из каталога проекта. Перечень для аспирантуры составлен по кодам и названиям из исходной структуры ЕПГУ. Для программ с указанными формами обучения в книге представлены все перечисленные формы. Для программ без указанной формы использована очная. Программа с отметкой об отсутствии набора представлена отозванными заявлениями.

В книге есть бюджет, платное обучение, особая, отдельная и целевая квоты. Распределение категорий, баллы и статусы предназначены для проверки приложения. ФИО, идентификаторы, телефоны и электронные адреса вымышлены.

Для загрузки войдите как сотрудник приёмной комиссии, выберите кампанию 2026 и откройте **Главное → Загрузить Excel**. Проверочный импорт в чистую базу обработал 10 000 заявлений без ошибок.
